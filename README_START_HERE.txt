GET STARTED
1. Unzip this folder, preserving the directory structure.
2. Open "index.html" for the Unit 4 homepage.
3. Select 4.1 Linear Momentum to open the interactive lesson.
4. The HTML pages and interactive models run locally without an Internet connection.
   The two external follow-up videos and official CED link require Internet access.
5. To publish online, upload the whole folder with paths intact. Set "index.html"
   as the unit homepage and keep the "lesson-04-01" and "resources" folders.
